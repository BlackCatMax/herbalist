# Herbalist

Симулятор травника + RPG в открытом мире фольклорного хоррора.

## Где что лежит

- `ProjectHerbalist/` — проект Unreal Engine 5.7 (модули `ProjectHerbalist` и
  `ProjectHerbalistTests`).
- `CHANGELOG.md` — летопись сделанного, с доводами и числами.
- `ROADMAP.md` — только то, что ещё открыто.
- `docs/` — инженерные документы проекта: дизайн-черновики, ресёрчи,
  аудиты, справочники, проверка в движке (оглавление — `docs/README.md`).
- `herbalist_docs/` — хранилище Obsidian: GDD (канон), глоссарий,
  компендиум, CSV/JSON данных таблиц.
- `tools/data_extraction/` — скрипты, выводящие json таблиц из компендиума.
- `Skills/` — навыки агентов.
