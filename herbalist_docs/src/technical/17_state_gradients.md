# 🔒 17. Градиенты состояния — UPDATED

---

## 🔒 17.1 Назначение

Градиенты состояния вычисляются для **анализируемых областей** мира (BiomeState), и используются для:

* анализа **пространственного распределения**
* генерации **особых событий**
* адаптации мира в **реальном времени**

---

## 🔒 17.2 Принцип работы

Градиент вычисляется через **сравнение соседних биомов**. Это даёт представление о **темпоральных и пространственных изменениях**.

---

### 1. Вводные данные

```python
def compute_gradient(biomes: Dict[Coord, BiomeState], coord: Coord) -> Dict[str, float]:
```

* **biomes** — коллекция всех биомов с их состоянием
* **coord** — текущая ячейка (x, y), для которой вычисляется градиент

---

### 2. Общий расчёт градиента

```python
def total_gradient_magnitude(grad: Dict[str, float]) -> float:
```

* Суммирует или агрегирует все компоненты градиента для вычисления общей величины.

---

## 🔒 17.3 Структура градиента

---

Градиент состоит из **различных компонентов**, каждая из которых отвечает за изменчивость **биомов** по соответствующему параметру.

---

```python
grad = {
    'toxicity': float,
    'fertility': float,
    'moisture': float,
    'competition': float,
    'disturbance': float,
    'time_of_day': float,
    'season': float
}
```

---

## 🔒 17.4 Агрегация

---

### Способы агрегации:

* **Среднее** значение по всем соседним ячейкам
* **Максимум** изменений для выделения значимых изменений
* **Минимум** для стабильных или устойчивых зон

---

### Пример агрегации:

```python
def aggregate_gradient(gradients: List[Dict[str, float]], method: str) -> Dict[str, float]:
    if method == 'mean':
        return {key: sum(g[key] for g in gradients) / len(gradients) for key in gradients[0]}
    elif method == 'max':
        return {key: max(g[key] for g in gradients) for key in gradients[0]}
    elif method == 'min':
        return {key: min(g[key] for g in gradients) for key in gradients[0]}
```

---

## 🔒 17.5 Связь с остальной системой

---

Градиенты используются для:

1. **Изменений в биомах** (повышение или снижение параметров на основе окружающих биомов)
2. **Генерации событий**, связанных с резкими изменениями в окружении
3. **Интерпретации пространства**, что помогает адаптировать систему к более сложным, динамичным условиям

---

## 🔒 17.6 Применение градиентов в pipeline

---

Градиенты влияют на:

```text id="v5k2m9"
S_real(x, y)
```

---

### Используются для:

1. **Morok** (влияние на Morok через изменения в градиенте)
2. **Zaryana** (адаптация с учётом градиента)
3. **Эвристические системы** (определение появления события на основе изменений)

## 🔒 17.8 Связь с событием

Градиенты могут служить основой для **генерации особых событий**:

* **Резкие изменения** в градиенте могут сигнализировать о наступлении критических событий (например, изменения в биоме, создание аномалий).
