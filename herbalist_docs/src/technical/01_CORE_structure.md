# 🔒 2. Структура состояния (CORE) — UPDATED

---

## 🔒 2.1 Базовая структура состояния

Состояние системы представляется как:

```text
S_real = (d, m, Meta)
```

где:

---

### Direction (Axes → нормализованный вектор)

```text
d = (body, mind, spirit, nature),  |d| = 1
```

* `body, mind, spirit, nature ∈ ℝ`
* после вычисления всегда выполняется **нормализация**

---

### Magnitude

```text
m ∈ [0, M_max]
```

---

### Meta

```text
potency, purity, stability, resonance, corruption ∈ ℝ
distortion ∈ [0,1]
```

---

## 📌 Интерпретация

| Компонент | Роль                             |
| --------- | -------------------------------- |
| `d`       | качественная структура состояния |
| `m`       | интенсивность состояния          |
| `Meta`    | модификаторы поведения системы   |

---

## 🔒 2.2 Связь Axes и Direction

Axes **не являются независимым состоянием**.

Они интерпретируются как:

```text
Axes_raw → Normalize → d
```

---

### Инвариант

```text
|d| = 1
```

---

👉 Это означает:

* абсолютные значения Axes не имеют значения
* важны только **соотношения**

---

## 🔒 2.3 Приращение состояния

Приращение задаётся как:

```text
ΔS = (Δd, Δm, ΔMeta)
```

---

### Обновление

```text
d' = Normalize(d + Δd)
m' = clamp(m + Δm - Decay(m), 0, M_max)
Meta' = Meta + ΔMeta
```

---

## 🔒 2.4 Meta как модификаторы (CORE)

Meta-параметры:

* не определяют состояние напрямую
* а **модифицируют вычисления**

---

### Основные роли

| Meta       | Влияние                          |
| ---------- | -------------------------------- |
| potency    | масштаб Δ                        |
| purity     | подавление шума                  |
| stability  | сопротивление изменениям         |
| resonance  | усиление совпадающих направлений |
| corruption | усиление искажений               |
| distortion | уровень восприятия Morok         |

---

## 🔒 2.5 Distortion (уточнение)

```text
distortion ∈ [0,1]
```

---

### Роль

* является **локальным параметром искажения**
* влияет на:

```text
Morok = f(distortion, D_total, History)
```

---

👉 важно:

* это не сам Morok
* а **его локальная интенсивность**

---

## 🔒 2.6 Разделение реальности и восприятия

Состояние существует в двух формах:

---

### Реальное состояние

```text
S_real = (d, m, Meta)
```

---

### Воспринимаемое состояние

```text
S_perceived = Distort(S_real, Morok)
```

---

### Разложение

```text
d_perceived = Normalize(d + Noise(M) + Bias(M))
m_perceived = m * (1 + ε(M))
Meta_perceived = Meta + Noise_meta(M)
```

---

## 🔒 2.7 Инварианты структуры

Система гарантирует:

```text
|d| = 1
0 ≤ m ≤ M_max
distortion ∈ [0,1]
```

---

Meta:

* не нормализуются
* но могут ограничиваться через clamp (SEMI)

---

## 🔒 2.8 Связь с Δ и системой

```text
ΔS = G(S_real, Intent_system, Context)
```

---

Meta участвуют:

* в вычислении Δ
* в вычислении Morok
* в стабилизации

---

## 🔒 2.9 Snapshot-семантика

Все компоненты:

```text
(d, m, Meta)
```

обновляются:

```text
одновременно из S_real(t)
```

---

👉 это исключает:

* зависимость от порядка
* частичные обновления
* скрытые циклы
