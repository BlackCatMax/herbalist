# 00. Core Lock — Инварианты системы

## 1. Единое состояние мира

## 1.2 Мир как граф состояний

Состояние мира не является изолированным в каждой точке. Биомы связаны в **ориентированный взвешенный граф влияний**:

- Каждый биом = узел с параметрами (AxisBias, MorokAffinity, ZaryanaAffinity)
- Связи = утечки контекста (MorokLeak, ZaryanaFlow, AxisDrift)

Изменение в одном биоме распространяется на соседей через рёбра графа. Это создаёт **непрерывное поле состояний**, где локальные действия имеют глобальные последствия.

Формально мир можно представить как:

World = Graph(Nodes, Edges) + Memory + WaveState

Где:
- Nodes — биомы с их параметрами
- Edges — направленные связи с весами влияния
- Memory — накопленная история каждого узла
- WaveState — текущее состояние распространяющихся волн [[Morok]] и [[Zaryana]]

> **Подробнее:** см. [[14_Biome_Graph]].


Мир игры представлен как единая система состояния. Это состояние не разделено на независимые подсистемы и не хранится в виде набора отдельных механик. Все изменения, происходящие в мире, выражаются через изменение этого состояния. Любое действие, совершаемое игроком, влияет не на отдельный объект или сущность, а на состояние мира как целого или его локальной части. Состояние мира непрерывно, взаимосвязано и изменяется во времени.

> **Техническая реализация:** см. [[S_real]] и [[GridWorldManager]] в [[03_Technical/Current/Core_Current|Техническая документация]].

## 1.1 Эталон состояния — [[S0|Алатырь]] ([[S0]])

В системе существует [[S0|эталонное состояние]] — [[S0]] ([[S0|Алатырь]]). Это не конкретная точка в пространстве и не физический объект. Это абстрактное состояние полной согласованности, в котором все параметры системы находятся в гармонии. [[S0]] не достигается напрямую, но используется как внутренний ориентир системы. Любое текущее состояние может быть рассмотрено как отклонение от [[S0]].

Это отклонение определяет:
- степень устойчивости состояния
- характер происходящих процессов
- уровень искажения ([[Morok]])
- читаемость мира для игрока

Фактическое состояние мира можно выразить как расстояние до эталона: Distance(BiomeState → [[S0]]). Чем больше это расстояние:
- тем выше нестабильность
- тем сильнее [[Morok|искажение]]
- тем сложнее интерпретация

## 2. Переход состояния

Состояние мира изменяется через переходы. Каждое действие игрока инициирует изменение, которое преобразует текущее состояние в новое: BiomeState(t) → BiomeState(t+1). Этот переход не является прямым применением действия. Он формируется через интерпретацию системой, которая учитывает:
- текущее состояние мира ([[S_real]])
- структуру действия
- [[Intent]] процесса ([[Intent]])
- уровень искажения ([[Morok]])

Таким образом, изменение можно представить как: ΔBiome = G(Action, Intent, BiomeState, Morok). Одно и то же действие может приводить к различным результатам в зависимости от контекста.

## 3. Единственный поток системы

Все процессы в игре подчиняются единому потоку: Player → Action → Transformation → BiomeState → Perception → Player. Этот поток является базовой структурой системы. Однако фактически он работает через два слоя состояния: [[S_real]] → Distortion([[Morok]]) → [[S_Perceived]].

Игрок не взаимодействует с реальным состоянием напрямую. Любое действие, решение или интерпретация основаны на искажённом восприятии:

Player → Action([[S_Perceived]]) → Transformation → [[Intent]] → ΔBiome → BiomeState ([[S_real]]') → Distortion([[Morok]]) → Perception([[S_Perceived]]) → Player

Таким образом:
- игрок действует на основе восприятия
- система изменяет реальное состояние
- результат снова искажается перед восприятием

Этот цикл является замкнутым и непрерывным.

**Важно:** В текущем прототипе слой [[S_Perceived]] **не реализован** (). UI показывает `S_real`. См. [[03_Technical/Current/Core_Current|Техническая документация]].

## 4. Единство системы

В системе отсутствуют независимые механики. Все элементы: ресурсы, преобразования, сущности, события, состояния — являются различными проявлениями единого состояния мира. Нет отдельной логики для «алхимии», «экологии» или «поведения существ». Все они являются частными случаями изменения [[BiomeState]].

## 5. Роли ключевых компонентов

### Сущности
Сущности не являются агентами и не обладают собственной логикой поведения. Они представляют собой проявления состояния мира: Entity = Projection([[BiomeState]]). Однако наблюдаемая игроком сущность является результатом искажения: Entity_real = Projection([[BiomeState]]), Entity_seen = Distort(Entity_real, [[Morok]]). Таким образом:
- сущности отражают состояние
- их восприятие может быть недостоверным
- игрок интерпретирует мир через искажённые проявления

Подробнее: [[09_Entities]].

### Преобразование (Алхимия)
Преобразования не являются фиксированными рецептами. Результат зависит от состояния системы: Result = f(ingredients, [[BiomeState]]). При этом действия игрока формируются через восприятие: Action = f([[S_Perceived]]). Это создаёт разрыв между ожидаемым и фактическим результатом.

Детали реализации: [[05_Systems]] и [[03_Technical/Current/Core_Current|Техническая документация]]Alchemy_Current]].

### Направленность ([[Intent]])
Намерение не задаётся напрямую. Оно формируется как структура действия: `Intent_player = F(Action([[S_perceived]]))`, `Intent_system = F(Action, [[BiomeState]])`. Таким образом:
- игрок формирует [[Intent]] через восприятие
- система интерпретирует его на основе реального состояния

Это допускает расхождение между предполагаемым направлением и фактическим эффектом. Подробнее: [[11_Intent_Evolution]].

### Капища
Капища представляют собой локальные области повышенной согласованности. Они:
- снижают уровень [[Morok]]
- повышают устойчивость состояния
- улучшают читаемость системы

Это приводит к уменьшению разрыва между [[S_real]] и [[S_Perceived]]. Капища не создают эффектов напрямую, но изменяют условия, в которых происходят изменения. **Статус:** реализованы v1 (2026-08-24, см. [[15_Cycles_And_Shrines]] §15.6) — эффекты 1/2/4 из четырёх; типоспецифичные бонусы и Буян ещё на уровне ГДД.

## 6. Причинность

В системе существует единственная причинная цепочка: `Player → изменение [[BiomeState]] → изменение мира → восприятие`. При этом действия игрока всегда основаны на восприятии: Player → Action([[S_Perceived]]) → ΔBiome. Сущности, события и другие элементы не инициируют изменения самостоятельно. Они являются следствием состояния.

## 7. Восприятие

Игрок не имеет прямого доступа к реальному состоянию мира. Восприятие формируется как искажённая версия: [[S_Perceived]] = Distort([[S_real]], [[Morok]]). Это означает:
- любое наблюдение уже интерпретировано
- [[Morok|искажение]] является частью системы
- достоверность не гарантирована

Игрок взаимодействует с миром через восприятие, а не напрямую.

## 8. Ошибка как часть системы

Ошибки не являются внешним нарушением. Они возникают как результат интерпретации: Error → Action → [[Intent]] → ΔBiome → NewState. Ошибка:
- изменяет состояние
- становится частью истории
- влияет на дальнейшие процессы

## 9. Локальность и распространение

Изменения происходят локально. Они могут затухать, распространяться или усиливаться. Влияние зависит от состояния среды и структуры изменений.

## 10. Накопление

Состояние мира накапливает изменения. Эти изменения взаимодействуют, усиливают друг друга, формируют устойчивые структуры. История состояния влияет на будущие реакции системы.

## 10.1 Замкнутый цикл системы

Все процессы образуют замкнутую структуру: [[S_real]] → Distortion([[Morok]]) → [[S_Perceived]] → PlayerAction → [[Intent]] → ΔBiome → [[S_real]]. Этот цикл является единственным механизмом изменения мира, основой всех систем и фундаментом игрового опыта.

## 11. Ограничения

Запрещено:
- вводить независимые системы
- создавать уникальные правила для отдельных объектов
- нарушать единую модель состояния

Любая новая механика должна быть выражена через изменение [[BiomeState]].

## 12. Итог

Мир игры представляет собой единую систему состояния. Игрок не управляет отдельными элементами, не задаёт эффекты напрямую, не работает с объективной реальностью. Он воспринимает искажённый мир, действует в рамках этого восприятия, изменяет состояние и сталкивается с последствиями. Система остаётся непрерывной, взаимосвязанной, интерпретируемой, но не полностью предсказуемой.
