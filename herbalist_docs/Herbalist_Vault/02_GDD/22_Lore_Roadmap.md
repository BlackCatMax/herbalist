      просили пересчитать); диапазон отклика (±0.2) оставлен —
      "не утаскивать ниже якоря" уже гарантировано структурно формулой
      `max(Anchor, Anchor+Response)`, диапазон отдельно решает только
      высоту потолка, не эту гарантию. Реально новое — скорость
      сходимости: раньше отклик применялся мгновенно, теперь
      сглажен (`ClarityResponseLerpRate=0.002`, экспоненциальный Lerp,
      тот же принцип, что `Memory.HistoryPurity`) — ~3.9 игровых суток до
      95% сходимости, обоснование расчёта в CHANGELOG.md.
- [ ] Пороги Гнильников/Берегини/капищ — расставлены для направления,

- [x] Точные пороги прогрева артефактов (`ArtifactWarmthGainPerBrew`/
