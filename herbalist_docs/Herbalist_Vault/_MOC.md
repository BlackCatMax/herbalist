## 🎯 Ключевые концепты

### Основная цель
Восстановить стабильность мира, искажённого [[Morok]]ом, и вернуть [[Zaryana|Заряну]] к жизни.

### Центральный цикл
Наблюдение → Интерпретация → Действие → Изменение → Новое наблюдение


### Фундаментальная формула
S_perceived = Distort(S_real, Morok)


### Нет фиксированных рецептов
Результат алхимии зависит от:
- Состава ингредиентов
- Порядка добавления
- Состояния биома
- Времени суток и фазы луны
- Уровня [[Morok]]
