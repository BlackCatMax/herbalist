# Широколиственный лес

![[assets/biomes/shirokolistvennye_lesa.png]]

##  Общее описание
Светлые дубравы и липовые рощи, где солнце проникает сквозь резную листву. Эти леса издавна почитались как священные — здесь легче всего ощутить дыхание Прави, а [[Morok]] отступает перед вековой мудростью деревьев.

- **Системная роль:** «Читаемость» (Clarify). Минимизирует искажение [[Morok]]а, делая результаты алхимии почти предсказуемыми.
- Идеальный биом для **обучения** и проверки гипотез.
- Высокая [[Stability]] (0.60) и [[Purity]] (0.70) дают стабильные, «чистые» зелья.
- Здесь игрок может точнее понять вклад каждого ингредиента.
