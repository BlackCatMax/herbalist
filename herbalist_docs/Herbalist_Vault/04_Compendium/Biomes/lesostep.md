# Лесостепь

![[assets/biomes/lesostep.png]]

## 🌍 Общее описание
Пограничье между лесными массивами и открытыми степными просторами. Здесь сталкиваются две стихии: спокойствие леса и буйство степи. Это место конфликта, где Морок проявляется особенно непредсказуемо, рождая странные гибридные формы.

- **Системная роль:** «Конфликт систем» (Conflict). Усиливает нестабильность при смешивании противоположных по духу ингредиентов.
- Средняя [[Stability]] (0.55) компенсируется высокой вероятностью резких скачков [[Distortion]].
- Идеальное место для создания «нестабильных», но мощных зелий.
- Риск и награда идут рука об руку.
