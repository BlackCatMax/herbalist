# Метельники

![[assets/bestiary/tundra/metelniki.png]]

##  Описание
Духи, кружащие в метелях и пурге. Сбивают с пути, заметают следы, завывают в ушах, уводя путника в гибельную белую мглу.

##  Параметры проявления
| Ось | Значение |
|-----|----------|
| Body | 0.40 |
| Mind | 0.30 |
| Spirit | 0.80 |
| Nature | 0.50 |

- **Сродство с [[Morok]]:** 0.70
- **Реакция на игрока:** агрессивны во время бури.

##  Опасность
- **Уровень угрозы:** Средний
- **Тип атак:** Потеря ориентации, обморожение, увязание в снегу.
- **Уязвимости:** Тепло, укрытие, обереги.

##  Где встретить**
Снежные бури, пурга.

##  Алхимическое значение
Снежинка из лапы метельника (пойманная в бутылку) — ингредиент для зелий хаоса и дезориентации.

##  Легенды и поверья
> *«В метель не ходи — метельники закружат, с пути собьют».*
