# Кувшинкины духи

![[assets/bestiary/poyma_rechnaya/kuvshinkiny_duhi.png]]

## 🪶 Описание
Малые духи, живущие в цветах кувшинок. По ночам они танцуют на воде, создавая круги и рябь. Могут подарить вдохновение или, наоборот, наслать сонливость.

## 📊 Параметры проявления
| Ось | Значение |
|-----|----------|
| Body | 0.10 |
| Mind | 0.30 |
| Spirit | 0.80 |
| Nature | 0.90 |

- **Сродство с [[Morok]]:** 0.40
- **Реакция на игрока:** пугливы, исчезают при приближении.

## ⚔️ Опасность
- **Уровень угрозы:** Низкий
- **Тип атак:** Сонливость, лёгкое головокружение.
- **Уязвимости:** Яркий свет.

## 📍 Где встретить
Заросли кувшинок в тихих заводях.

## 🧪 Алхимическое значение
Лепесток кувшинки, «поцелованный» духом, усиливает [[Spirit]] и [[Resonance]].

## 📜 Легенды и поверья
> *«В кувшинках духи спят — не рви цветы без нужды, сон украдёшь».*
