# Морочники

![[assets/bestiary/povsemestno/morochniki.png]]

## 🪶 Описание
Мелкие духи, питающиеся заблуждениями и страхами. Искажают восприятие: меняют голоса, показывают ложные тропы, создают иллюзии. Прямые слуги [[Morok]].
