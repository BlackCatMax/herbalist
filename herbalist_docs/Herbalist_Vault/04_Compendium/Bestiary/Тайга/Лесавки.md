# Лесавки

![[assets/bestiary/tayga/lesavki.png]]

## 🪶 Описание
Мелкие лесные духи, похожие на маленьких старичков с листьями вместо волос. Живут в листве и ветках, любят шуршать и путать листья под ногами.
