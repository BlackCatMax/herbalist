# Propagation

**GDD:** Процесс распространения волн `Morok` и `Zaryana` по рёбрам графа с фиксированным временным шагом. Не глобальный коэффициент, а волны влияния, которые перетекают из узла в узел, постепенно затухая. Создаёт непрерывное поле состояний.

**Tech:** Реализован в `UBiomeGraphSubsystem::PropagateWaves`. На основе snapshot’а текущих полей для каждого узла вычисляются дельты: `DeltaMorok = MorokField * MorokLeak`, `DeltaZaryana = ZaryanaField * ZaryanaFlow`. Затем дельты добавляются к полям соседних узлов. Происходит каждый фиксированный шаг (0.2 сек) до применения полей к Grid.

**Восприятие:** Игрок видит, что изменение одного биома со временем влияет на соседние — болото может «заражать» близлежащий лес, а стабильная дубрава — успокаивать окраины.
