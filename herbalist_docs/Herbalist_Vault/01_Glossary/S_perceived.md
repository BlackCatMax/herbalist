# S_perceived

**GDD:** Воспринимаемое состояние мира, доступное игроку через наблюдение и интерпретацию. Формируется как искажённая версия [[S_real]] под воздействием [[Morok]]. Игрок никогда не взаимодействует с [[S_real]] напрямую — только с S_perceived.

**Tech:** Формально: `S_perceived = Distort(S_real, Morok)`. Функция `Distort` нелинейна, зависит от уровня [[Morok]] и может включать шум, обмен компонент и неоднозначные преобразования. **В текущем прототипе НЕ РЕАЛИЗОВАНО** — UI показывает `S_real`.

**Восприятие:** Для игрока S_perceived и есть мир. Искажения проявляются как несоответствие ожиданий и результатов, противоречивые признаки, нестабильность поведения знакомых элементов, ложные сущности и миражи.
