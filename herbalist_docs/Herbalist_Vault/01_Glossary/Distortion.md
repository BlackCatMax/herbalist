# Distortion

**GDD:** Локальная мера присутствия [[Morok]]. Искажает восприятие и результаты алхимии. Внутренняя искажённость, отклонение от нормы.

**Tech:** `Meta.Distortion ∈ [0,1]`. Входной параметр для нелинейного искажения в [[Alchemy]]. Увеличивается от стресса сбора (`HarvestStress`). Ключевой параметр для [[Bifurcation]].

**Восприятие:** Рябь, неестественные переливы, «неправильность», мерцание на иконке.
