# Distortion (Искажение)

**GDD:** Локальная мера присутствия [[Morok]]. Искажает восприятие и результаты.

**Tech:** `Meta.Distortion ∈ [0,1]`. Входной параметр для нелинейного искажения в [[Alchemy]].

**Восприятие:** Рябь, неестественные переливы, «неправильность».

**Связи:**
- Увеличивается от стресса сбора
- Ключевой параметр для бифуркации
