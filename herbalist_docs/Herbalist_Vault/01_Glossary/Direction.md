# Direction

**GDD:** Общее название для четырёх осей, определяющих качественную направленность состояния: [[Body]], [[Mind]], [[Spirit]], [[Nature]]. Задаёт пропорцию, а не абсолютную силу.

**Tech:** Вектор осей `d = [Body, Mind, Spirit, Nature]` всегда нормируется по сумме компонент до 1. Определяет тип будущего зелья в [[Alchemy]].

**Восприятие:** Игрок интерпретирует Direction через цвет и текстуру ингредиента, доминирующий стихийный оттенок, характер эффекта зелья.
