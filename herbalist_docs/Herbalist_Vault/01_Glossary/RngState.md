# RngState

**GDD:** Детерминированный источник случайности в системе.

**Tech:** Функция `Random01` в коде не существует. Пайплайн (`PipelineV2.cpp`) держит единый тип ГПСЧ — стандартный `FRandomStream` движка (UE), передаваемый по цепочке вызовов. `FRngState` (с полем `Seed`) в коде остался, но для другого, вырожденного случая (`NormalizeL2`/`ToL2`) — сознательно не смешивается с `FRandomStream` пайплайна. Используется в [[Alchemy]] (шум [[Morok]]) и [[GridWorldManager]] (генерация ресурсов).

**Восприятие:** Не воспринимается напрямую. Обеспечивает вариативность результатов при одинаковых входных данных.
