# RngState

**GDD:** Детерминированный источник случайности в системе.

**Tech:** `FRngState` с полем `Seed`. Функция `Random01` — линейный конгруэнтный генератор (`Seed = Seed * 196314165 + 907633515`). Используется в [[Alchemy]] (шум [[Morok]]) и [[GridWorldManager]] (генерация ресурсов).

**Восприятие:** Не воспринимается напрямую. Обеспечивает вариативность результатов при одинаковых входных данных.
