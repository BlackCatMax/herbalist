# Potency (Мощность)

**GDD:** «Внутренняя сила» ингредиента или места.

**Tech:** `Meta.Potency ∈ [0,1]`. Масштабирует все компоненты [[Delta]].

**Восприятие:** «Концентрация», «насыщенность».

**Связи:**
- Усиливает эффект алхимии
- Может расти при «вызревании» ресурса
