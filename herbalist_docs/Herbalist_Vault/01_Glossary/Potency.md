# Potency

**GDD:** «Внутренняя сила» ингредиента или места. Мощь воздействия, эффективность.

**Tech:** `Meta.Potency ∈ [0,1]`. Масштабирует все компоненты [[Delta]] в алхимии. Может расти при «вызревании» ресурса в инвентаре.

**Восприятие:** «Концентрация», «насыщенность». Сильное зелье действует мощнее и дольше.
