# Magnitude (Магнитуда)

**GDD:** «Жизненная сила», интенсивность проявления.

**Tech:** Скаляр `m ∈ [0,1]` в `FRealState`. Определяет общую «силу» эффекта.

**Восприятие:** «Слабое» / «Сильное» / «Концентрированное».

**Связи:**
- Масштабирует [[Delta]] в алхимии
- Снижается при разбавлении водой
