# BiomeState

**GDD:** Динамическое состояние биома в точке: сезон, погода, жизненная сила. Влияет на доступность ресурсов и результаты алхимии.

**Tech:** Получает данные от [[GridWorldManager]]. **В текущем прототипе НЕ РЕАЛИЗОВАНО** — биомы статичны.

**Восприятие:** Игрок ощущает через внешний вид местности, атмосферу, поведение ресурсов и присутствие сущностей.
