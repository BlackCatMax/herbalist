# BiomeState

**GDD:** Динамическое состояние биома в точке: сезон, погода, жизненная сила. Влияет на доступность ресурсов и результаты алхимии.

**Tech:** Получает данные от [[GridWorldManager]]. **Реализовано** — биомы полностью динамичны через `UBiomeGraphSubsystem`: распространение полей Morok/Zaryana по узлам биомного графа, затухание/утечка полей, накопление памяти/нестабильности, плюс гейты сезона, погоды и фазы луны на то, что можно собрать.

**Восприятие:** Игрок ощущает через внешний вид местности, атмосферу, поведение ресурсов и присутствие сущностей.
