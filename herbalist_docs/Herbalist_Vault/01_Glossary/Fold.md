# Fold (Агрегация)

**GDD:** Объединение ресурсов в алхимии с учётом порядка.

**Tech:** `Pipeline::Fold`:
- Вес первого ингредиента = 1.0
- Каждого следующего = предыдущий * 0.8
- Взвешенное среднее всех параметров
- Нормализация [[Direction]] по сумме.

**Связи:**
- Используется в [[Alchemy]] для не-водных ингредиентов
