# Fold

**GDD:** Агрегация — объединение ресурсов в алхимии с учётом порядка. Первый ингредиент имеет наибольший вес.

**Tech:** `Pipeline::Fold`: вес первого = 1.0, каждого следующего = предыдущий * 0.8. Взвешенное среднее всех параметров. Нормализация [[Direction]] по сумме. Используется для не-водных ингредиентов.

**Восприятие:** Порядок добавления ингредиентов меняет результат. Игрок учится «правильным» последовательностям.
