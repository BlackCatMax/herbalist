# Resonance (Резонанс)

**GDD:** «Сродство» компонентов, гармония с миром.

**Tech:** `Meta.Resonance ∈ [0,1]`. Усиливает совпадающие направления в [[Direction]].

**Восприятие:** Мягкое свечение, ощущение «правильности».

**Связи:**
- Усиливает доминирующие оси
- Не зависит от воды в алхимии
