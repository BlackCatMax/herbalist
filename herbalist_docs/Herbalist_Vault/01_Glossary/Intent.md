# Intent (Намерение)

**GDD:** Направленность действия, формируемая процессом. Определяет, как результат встраивается в мир.

**Tech:** `FIntent` с единственным полем `Coherence`. В текущем коде всегда передаётся `0.5f`.

**Планируется:** Динамическое вычисление из последовательности действий и `S_perceived`.

**Связи:**
- Используется в [[Alchemy]] для расчёта `ZaryanaStrength`
