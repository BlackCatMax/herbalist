# Intent

**GDD:** Направленность действия, формируемая процессом. Определяет, как результат встраивается в мир. Не задаётся напрямую, а возникает из последовательности действий.

**Tech:** ComputeIntentCoherence([[Atoms]], [[GlobalDistortion]]) — учитывает порядок, качество, классы, Distortion. **Реализовано: Фаза 4.**

**Восприятие:** Игрок ощущает Intent через стабильность результата и его «вписывание» в мир. Согласованные действия дают устойчивый эффект.
