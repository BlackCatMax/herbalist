# Inventory

**GDD:** Инвентарь — продолжение состояния мира. Предметы не застывают, а продолжают эволюционировать под действием времени и внутренних процессов (порча, вызревание).

**Tech:** Компонент `UHerbalistInventoryComponent`. Хранит `TArray<FInventoryItem>`. Предметы стекуются, если близки по параметрам. При слиянии параметры усредняются с деградацией.

**Восприятие:** Игрок видит изменение иконки (цвет, прозрачность, прожилки) и текстового описания. «Увядший лист» вместо «свежий лист».
