# Stability (Стабильность)

**GDD:** Насколько состояние «держит форму». Сопротивление изменениям.

**Tech:** `Meta.Stability ∈ [0,1]`. Снижает величину [[Delta]] и вероятность катастрофы.

**Восприятие:** Ровное течение процесса, отсутствие резких скачков.

**Связи:**
- Повышается при [[Zaryana]]
- Снижается при высоком [[Distortion]]
