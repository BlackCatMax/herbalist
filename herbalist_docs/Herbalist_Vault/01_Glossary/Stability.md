# Stability

**GDD:** Насколько состояние «держит форму». Сопротивление изменениям, устойчивость к внешним воздействиям.

**Tech:** `Meta.Stability ∈ [0,1]`. Снижает величину [[Delta]] и вероятность катастрофы. Повышается при [[Zaryana]], снижается при высоком [[Distortion]].

**Восприятие:** Ровное течение процесса, отсутствие резких скачков. Стабильное зелье не портится долго.
