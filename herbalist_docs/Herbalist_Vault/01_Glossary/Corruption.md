# Corruption (Скверна)

**GDD:** Накопленная «порча», тёмное влияние.

**Tech:** `Meta.Corruption ∈ [0,1]`. Увеличивает негативные эффекты, усиливает конфликты осей.

**Восприятие:** Тёмные прожилки, мутность, «грязный» оттенок.

**Связи:**
- Увеличивает [[Distortion]] в алхимии
- Снижает [[Purity]] и [[Stability]]
