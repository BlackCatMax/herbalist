# Corruption

**GDD:** Накопленная «порча», тёмное влияние, скверна. Степень «загрязнённости», склонность к негативным эффектам.

**Tech:** `Meta.Corruption ∈ [0,1]`. Увеличивает негативные эффекты, усиливает конфликты осей. Увеличивает [[Distortion]] в алхимии, снижает [[Purity]] и [[Stability]].

**Восприятие:** Тёмные прожилки, мутность, «грязный» оттенок. «Цена», которую придётся заплатить за использование.
