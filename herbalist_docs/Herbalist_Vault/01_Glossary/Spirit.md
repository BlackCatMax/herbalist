# Spirit

**GDD:** Духовное начало. Воля, мораль, связь с иным миром (Навью), присутствие сущностей. Одна из четырёх осей [[Direction]].

**Tech:** Компонент `Direction`. Диапазон `[0,1]` после нормализации.

**Восприятие:** Высокое значение — «благословение», «присутствие», связь с духами. Низкое — «бездуховность», «пустота». Усиливается в ночное время и в особых местах.
