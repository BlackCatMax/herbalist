# Spirit (Дух)

**GDD:** Духовное начало. Воля, мораль, связь с иным миром (Навью).

**Tech:** Компонент [[Direction]].

**Восприятие:** Высокое значение — «благословение», «присутствие». Низкое — «бездуховность», «пустота».

**Связи:**
- Конфликтует с [[Body]]
- Усиливается в ночное время
