# Body (Тело)

**GDD:** Телесное, физическое начало. Связано с силой, выносливостью, здоровьем, материальностью.

**Tech:** Компонент [[Direction]] в `FRealState`. Диапазон `[0,1]` после нормализации.

**Восприятие:** Высокое значение ощущается как «тяжесть», «плотность», «жар». Низкое — «слабость», «хрупкость».

**Связи:**
- Используется в [[Alchemy]]
- Влияет на [[Magnitude]]
- Может конфликтовать с [[Spirit]]
