# Body

**GDD:** Телесное, физическое начало. Связано с силой, выносливостью, здоровьем, материальностью. Одна из четырёх осей [[Direction]].

**Tech:** Компонент `Direction` в `FRealState`. Диапазон `[0,1]` после нормализации суммы.

**Восприятие:** Высокое значение ощущается как «тяжесть», «плотность», «жар». Низкое — «слабость», «хрупкость». В алхимии даёт эффекты, связанные с физическим телом.
