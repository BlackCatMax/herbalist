# Fertility

**GDD:** Плодородие биома. Определяет количество и качество растительных ресурсов.

**Tech:** `Environment.Fertility ∈ [0,1]`. Проверено 2026-09-06: поле **только
записывается** — `AGridWorldManager::ApplyFertilizerToCell` поднимает его при
внесении Перегноя (`GridWorldManagerCore.cpp:1602`), но нигде в коде не
читается обратно. На регенерацию/количество/качество ресурсов сейчас не
влияет вовсе, вопреки описанию GDD — реальный крючок на будущее, не рабочая
механика.

**Восприятие:** «Живая», «богатая» земля — задумано, не реализовано.
