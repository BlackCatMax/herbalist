# Fertility

**GDD:** Плодородие биома. Определяет количество и качество растительных ресурсов.

**Tech:** `Environment.Fertility ∈ [0,1]`. Влияет на регенерацию ресурсов в клетке.

**Восприятие:** «Живая», «богатая» земля. Больше ресурсов, быстрее восстанавливаются.
