# Fertility

**GDD:** Плодородие биома. Определяет количество и качество растительных ресурсов.

**Tech:** `Environment.Fertility ∈ [0,1]`. Проверено 2026-09-06: поле **только
записывается** — `AGridWorldManager::ApplyFertilizerToCell` поднимает его при
внесении Перегноя (`GridWorldManagerCore.cpp:1602`), но нигде в коде не
читается обратно. На регенерацию/количество/качество ресурсов сейчас не
влияет вовсе, вопреки описанию GDD — реальный крючок на будущее, не рабочая
механика.

**Восприятие:** «Живая», «богатая» земля — задумано, не реализовано.

**Связанная величина, уже рабочая:** `UHerbalistSettings::StressRecoveryMultiplier`
по биомам выводится из Fertility (и характера воды) через `extract_biomes.py`,
до 2026-09-07 стоял нейтральной единицей у всех восьми биомов — механика
«место держит след дольше/меньше» была реализована, но фактически выключена. Сейчас
по документации (убывание стресса медленнее в богатых местах): Болото 1.717
(12 игровых суток против базовых 7), Тундра 1.642, Степь 1.296, Лесостепь 0.797,
Тайга 0.668, Широколиственный лес 0.657, Пойма 0.636, Смешанный лес 0.588.
