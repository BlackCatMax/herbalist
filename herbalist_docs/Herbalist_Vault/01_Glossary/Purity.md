# Purity

**GDD:** «Чистота» в народном понимании. Отсутствие примесей и скверны. Определяет предсказуемость и «правильность» эффекта.

**Tech:** `Meta.Purity ∈ [0,1]`. Подавляет негативные эффекты, улучшает предсказуемость. Повышается при [[Zaryana]], снижается при смешивании разных ресурсов.

**Восприятие:** Прозрачность, блеск, отсутствие мути. Чистое зелье даёт ожидаемый результат без побочных эффектов.
