# Purity (Чистота)

**GDD:** «Чистота» в народном понимании. Отсутствие примесей и скверны.

**Tech:** `Meta.Purity ∈ [0,1]`. Подавляет негативные эффекты, улучшает предсказуемость.

**Восприятие:** Прозрачность, блеск, отсутствие мути.

**Связи:**
- Повышается при [[Zaryana]]
- Снижается при смешивании разных ресурсов
