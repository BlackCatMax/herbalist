# Nature

**GDD:** Природное, дикое начало. Рост, трансформация, связь с живым миром, жизненная сила. Одна из четырёх осей [[Direction]].

**Tech:** Компонент `Direction`. Диапазон `[0,1]` после нормализации.

**Восприятие:** Высокое значение — «живое», «буйное», связь с лесом. Низкое — «увядание», «бесплодие». Усиливается во влажных биомах и в дикой местности.
