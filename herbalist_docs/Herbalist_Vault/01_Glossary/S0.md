# S₀ (Алатырь)

**GDD:** Эталонное состояние абсолютной гармонии. Ориентир, к которому стремится мир.

**Tech:** `FAlatyr::S0`:
- `Direction` = (0.5, 0.5, 0.5, 0.5) нормализованный
- `Magnitude` = 0.5
- `Distortion` = 0, `Stability` = 1, `Purity` = 1
- Остальные `Meta` = 0

Используется в [[Harvest]] для расчёта отклонения биома.

**Восприятие:** Недостижимый идеал, «правильное» состояние.
