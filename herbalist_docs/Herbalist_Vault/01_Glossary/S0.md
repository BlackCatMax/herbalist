# S0

**GDD:** Эталонное состояние абсолютной гармонии — Алатырь. Ориентир, к которому стремится мир. Недостижимый идеал, относительно которого измеряется отклонение текущего состояния.

**Tech:** `FAlatyr::S0` (пересчитано 2026-08-24, L1 вместо L2 — старые значения ниже устарели):
- `Direction` = (0.25, 0.25, 0.25, 0.25) — L1-нормализовано из (1,1,1,1)
- `Magnitude` = 1.0
- `Distortion` = 0, `Corruption` = 0
- `Stability` = 1, `Purity` = 1, `Potency` = 1, `Resonance` = 1

Больше **не** используется в [[Harvest]] — вынесен из формулы сбора намеренно
(плохо работал началом координат). Реальная роль — недостижимый ориентир
прогрессии: `HerbalistCore::Math::Distance(State, FAlatyr::S0)` в метрике
мира Заряны/Буяна и отладочной строке клетки (`GetSelectedCellInfo`).

**Восприятие:** «Правильное», гармоничное состояние. Игрок ощущает близость к Алатырю через стабильность среды и предсказуемость результатов.
