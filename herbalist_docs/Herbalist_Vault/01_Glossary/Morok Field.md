# Morok Field

**GDD:** Runtime-поле узла графа. С 2026-09-07 — **знаковое отклонение**
[-1, 1] текущего Distortion биома от его природного (дефолтного) значения,
не абсолютная сила Морока. Ноль = «биом в своей природе». Абсолютный
уровень («насколько тут грязно на самом деле») получают через
`UBiomeGraphSubsystem::GetAmbientMorok(BiomeID)` = `clamp(дефолт биома +
поле, 0, 1)` — именно эта величина сравнивается с порогами Легендарных
сущностей и вкладом места в варку, не поле напрямую.

**Tech:** Поле `MorokField` в `FBiomeGraphNode` (`float`, [-1,1]).
Обновляется в трёх местах, в этом порядке за шаг графа (`InternalStep`,
`FixedTimeStep = 0.2с`):
1. `RecalculateFieldsFromGrid` — усредняет `(Cell.State.Meta.Distortion −
   дефолт биома)` по клеткам биома, подмешивает в поле лерпом
   (`GridBlendFactor = 0.3`, масштабирован на `dt/0.2` при отличном шаге).
2. `PropagateWaves` — **настоящая консервативная диффузия**: поток
   вычитается из источника и прибавляется приёмнику
   (`ΔM(To) += Flow; ΔM(From) −= Flow`), сумма поля по всему графу
   сохраняется (было наоборот — копирование в обе стороны создавало Морок
   из ничего). `MorokLeak` ребра — 0.10–0.25 (по 14 рёбрам DA_BiomeGraph:
   0.15 у восьми, 0.10 у четырёх, 0.25 у двух).
3. `UpdateMemories` — экспоненциальный распад к нулю
   (`GlobalMorokDecay = 0.01/с`).

Затем `ApplyBiomeInfluences` тянет `TargetState.Distortion` к `дефолт биома
+ поле` («дырявое ведро», `MorokDistortionPushRate = DecayRate = 0.01`) —
пропускается целиком для клеток в бистабильном полюсе
(`Cell.Memory.bDegrading`). Полный вывод формул и точка равновесия —
`MATH_REFERENCE.md §3, §6.1`.

**Восприятие:** Игрок замечает, что в некоторых биомах алхимия становится
более хаотичной, а результаты — менее предсказуемыми. Это ощущается как
«неспокойное место» — но норма у каждого биома своя (Тайга спокойна уже
при Distortion 0.25, Болото — только ниже своих родных 0.70).
