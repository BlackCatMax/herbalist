# Mind (Разум)

**GDD:** Ментальное начало. Ясность, знание, восприятие, память.

**Tech:** Компонент [[Direction]]. Диапазон `[0,1]`.

**Восприятие:** Высокое значение — «ясность», «острота ума». Низкое — «туман», «забывчивость».

**Связи:**
- Используется в [[Alchemy]]
- Конфликтует с [[Nature]]
