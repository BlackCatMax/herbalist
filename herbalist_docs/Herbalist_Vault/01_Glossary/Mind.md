# Mind

**GDD:** Ментальное начало. Ясность, знание, восприятие, память, рациональное мышление. Одна из четырёх осей [[Direction]].

**Tech:** Компонент `Direction`. Диапазон `[0,1]` после нормализации.

**Восприятие:** Высокое значение — «ясность», «острота ума», способность видеть скрытое. Низкое — «туман», «забывчивость», подверженность иллюзиям.
