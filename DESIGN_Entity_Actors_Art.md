# Проявление сущностей — визуал, по аналогии с POI

Дополняет `16_Entity_Manifestation.md` тем же способом, что
`DESIGN_POI_Art_And_LevelDesign.md` дополнил POI-главу — механика
реализована практически полностью (Низший, Основной, 16 из 17
Легендарных), физического актора/визуала нет вообще ни у одного. Черновик,
как источник.

## Принцип охвата — три архетипа, не 60 индивидуальных решений

Механика уже систематизирована по рангу (§16.2/16.3/16.4) — визуал
наследует ту же систематизацию. Штучная проработка ниже — только для
**11 «флагманов»**: четыре из исходного вертикального среза (Гнильники,
Полевик, Берегиня, Морочники) и восемь дающих артефакт Легендарных
(частично уже описаны через сам артефакт в `21_Journey_And_Artifacts`,
здесь — визуал СУЩЕСТВА, не предмета). Остальные ~50 карточек наследуют
архетип своего ранга без изменений — деталь окраски/звука можно взять из
уже написанного текста карточки, не изобретать заново.

## Архетип 1 — Низший (амбиентная зона)

**Никакого физического тела.** Это порча воздуха/земли, не существо с
силуэтом — визуал должен читаться как атмосфера, не как персонаж. Лёгкий
партикл-слой (пыльца/споры/мошка/иней — по д-манифесту конкретной
карточки) над клеткой, где `ManifestedEntityID` установлен, плюс
локальное затемнение/десатурация в радиусе клетки. Звук — направленный
шёпот/шелест на самой границе слышимости, не громче окружения.

**Уровень:** ничего не размещается вручную — зона появляется/исчезает
там же, где уже появляется/исчезает `ManifestedEntityID` в коде, без
привязки к конкретной точке на карте.

## Архетип 2 — Основной («хозяин» места)

**Признак присутствия, не полная модель.** Клетка-landmark получает
предмет-маркер (характерный для конкретного «хозяина» — примятый круг
травы, сложенные ветки, перевёрнутый предмет обихода) плюс РЕДКОЕ, краткое
появление силуэта на периферии зрения игрока (2-3 секунды, размыто, не
анимировано детально) при пересечении порога Respect в любую сторону —
не постоянное присутствие. «Хозяин» ощущается, а не наблюдается.

**Уровень:** landmark уже размещён кодом (`SeedTestLandmarks`/аналоги) —
маркер-меш ставится на ту же клетку без дополнительной расстановки.

## Архетип 3 — Легендарный (якорная клетка)

**Единственный ранг, где оправдано вложиться в узнаваемый разовый образ**
— эффект редкий (одна клетка-якорь на весь биом, порог высокий).
Стандартный шаблон: сильный, короткий VFX-всплеск на клетке-якоре в
момент срабатывания триггера (не постоянный) + характерный именно этому
существу звук (не общий), плюс постоянный слабый маркер на клетке-якоре
(чтобы игрок мог найти её снова взглядом даже когда эффект неактивен).
11 флагманов ниже уточняют, что именно.

## Флагманы

### Гнильники (Низший, Болото — исходный срез)

Архетип 1 плюс уточнение: партикл — не пыльца, а тёмные хлопья гнили,
поднимающиеся снизу вверх (обратное обычной пыли), десатурация в сторону
бурого. Звук — влажный, чуть чавкающий шелест, не сухой.

### Полевик (Основной, Лесостепь — исходный срез)

Маркер — примятый в неровный круг участок поля, колосья вокруг лежат
внутрь круга, не наружу. Силуэт при высоком Respect — сутулая фигура,
почти сливающаяся с высокими колосьями, видна только со спины/боку,
никогда анфас. При низком/отрицательном Respect — маркер темнеет
(подгнившие колосья внутри круга), силуэта не появляется вовсе —
Полевик не показывается тому, кем недоволен.

### Берегиня (Легендарный, Речная пойма — исходный срез + артефакт)

Всплеск на клетке-якоре — не существо, а сама вода на миг становится
неестественно прозрачной до дна, будто подсвечена изнутри, с рябью,
идущей против течения. Звук — единственный чистый, долгий тон, как от
проведённого по кромке бокала пальца, без источника-переспроса «кто
поёт». Гребень (артефакт) визуально лежит на видном камне у якорной
клетки до момента получения — не в невидимом «инвентаре мира».

### Морочники (Опасная нечисть, повсеместно — исходный срез)

**Без актора вовсе, сознательно.** Уже зафиксировано в главе: Морочники —
не существо, а имя для `PerceiveValue()`. Единственный флагман, для
которого «визуал» — это НЕ добавлять никакого физического проявления,
только убедиться, что искажение тултипа/росы ночью визуально заметно
само по себе (мерцание цифр, дрожание текста) — сама неопределённость
источника и есть образ.

### Гамаюн (Легендарный, Лесостепь — артефакт: Зеркальце)

Всплеск на якоре — не сама птица, а её тень, пролетающая по земле без
видимого источника в небе (тень есть, птицы нет). Звук — один долгий,
чистый крик, не мелодия. Зеркальце лежит на земле под якорной клеткой
после срабатывания — предмет, не выдача из ниоткуда.

### Мать-Сыра-Земля (Легендарный, Степь — артефакт: Клубочек)

Не силуэт, а сама земля на якорной клетке идёт едва заметной волной,
как дыхание, один раз, медленно. Звук — низкий, почти инфразвуковой гул,
скорее ощущается, чем слышится. Клубочек находится в небольшой ямке в
земле, будто прорастает из неё, а не лежит поверх.

### Индрик-зверь (Легендарный, Тайга — артефакт: Рог)

Единственный флагман с реальным, хоть и мимолётным силуэтом целиком —
крупная тень зверя вдалеке, среди деревьев, никогда не приближается,
видна секунду-две на пределе видимости. Звук — низкий рёв/рокот, как
далёкий обвал, не рычание. Рог найден воткнутым в землю на месте, где
стоял силуэт.

### Дуб-старец (Легендарный, Широколиственный лес — артефакт: Яблоко)

Не движение существа — сам дуб-якорь единственный во всём лесу не
шелестит на ветру, пока остальные деревья вокруг раскачиваются. Полная,
неестественная тишина именно у него — не звуковой эффект, а его
отсутствие. Яблоко лежит у корней, не на ветвях (не нужно карабкаться).

### Баба-Яга (Легендарный, Смешанный лес — артефакт: Шапка-невидимка)

Единственная с буквальным, узнаваемым архетипом — силуэт избушки видна
на якорной клетке ВСЕГДА (не только при срабатывании триггера, в отличие
от остальных Легендарных), но развёрнута иначе при честном/обманном
исходе: к игроку передом при успешном испытании, задом — если провалено
(классический фольклорный мотив «встань к лесу задом»), это и есть
единственная механически читаемая обратная связь по исходу до получения
предмета.

### Волот (Легендарный, Тундра — артефакт: Камень-оберег)

Всплеск — не существо, а сама земля/снег на якорной клетке едва заметно
проседает, будто под очень большим весом, который тут же снят. Звук —
одиночный низкий удар, как далёкий шаг, не серия. Камень-оберег после
срабатывания лежит в свежей вмятине.

### Болотный царь (Легендарный, Болото — артефакт: Фонарь, только обманом)

Единственный флагман без «честного» силуэта вовсе — раз путь к нему
только обман, у него нет благообразного проявления для награды.
Постоянный маркер на его якорной клетке — Фонарь физически висит на
суку у воды, горит собственным светом. При попытке кражи (сцена обмана,
`21_Journey_And_Artifacts §21.3`) — водная гладь рядом идёт кругами без
видимой причины, единственный признак, что Царь «услышал» и отвлёкся
на приманку.

## Статус

📐 Запланировано, не реализовано — ни один из трёх архетипов, ни одна
из 11 бесп��шных проработок выше. Приоритет для промпта: сперва три
архетипа (покрывают всё разом), затем флагманы по порядку значимости
для игрока (Гнильники/Полевик/Берегиня как первое знакомство игрока с
механикой, Легендарные — по мере того, в каком порядке игрок реально
будет их находить).
