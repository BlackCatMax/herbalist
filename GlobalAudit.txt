- Проверить, что **раздел X.Y действительно существует** в целевом документе (учитывая, что разные документы имеют свою нумерацию).

## 1. Базовые проверки

1. Detect ALL inconsistencies between documents:
   - logical contradictions
   - mismatched definitions
   - pipeline order conflicts
   - violations of declared invariants
   - terminology inconsistencies
   - missing links between systems
   - incorrect data flow descriptions

2. Detect INTERNAL issues inside each document:
   - broken invariants
   - contradictions between sections
   - incorrect stage ordering
   - undefined variables or parameters
   - duplicated or conflicting logic

3. Detect CORE VIOLATIONS:
   - any system contradicting CORE
   - any system bypassing CORE rules
   - any redefinition of CORE concepts
   - any hidden logic not aligned with CORE
