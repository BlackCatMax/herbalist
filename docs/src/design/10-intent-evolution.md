# 10. Intent и эволюция мира

## 10.1 Что такое intent

**Intent** — это выбор игрока **перед варкой зелья**, определяющий, для какой цели он создаёт зелье.

Игрок выбирает intent из семи вариантов:

| Intent | Значение | Пример использования |
|:---|:---|:---|
| `healing` | Исцеление | Лечение болезней, восстановление здоровья |
| `cleansing` | Очищение | Снятие порчи, очищение места |
| `growth` | Рост | Увеличение плодородия, ускорение роста |
| `protection` | Защита | Создание оберега, защита от духов |
| `harm` | Вред | Нанесение урона, проклятие |
| `ritual` | Ритуал | Обрядовое действие, призыв духов |
| `sacrifice` | Жертва | Отказ от чего-то ради высшей цели |

## 10.2 Как intent влияет на Zaryana

Zaryana — этап структурирования результата. Intent **изменяет силу этого структурирования**:

- Каждый intent имеет свой коэффициент усиления (например, `healing` = 1.2, `harm` = 0.8).
- Чем выше коэффициент, тем более «чистым» и предсказуемым становится результат после прохождения этапа Zaryana.
- Если intent не выбран, используется нейтральный коэффициент 1.0.

**Простыми словами:** Intent — это «намерение», которое помогает системе понять, какой результат ожидается. Выбор подходящего intent (исцеление для целебного зелья, очищение для ритуала очистки)
даёт более стабильный и предсказуемый результат.
Неподходящий intent (например, `harm` для целебного зелья) снижает эффективность структурирования, но система не проверяет состав автоматически — это остаётся на усмотрение игрока.

**Простыми словами:** Intent — это «намерение», которое помогает системе понять, какой результат ожидается. Чем точнее игрок выбирает intent, тем лучше система может «отфильтровать» искажения.

## 10.3 Как intent влияет на эволюцию мира

Каждый тип intent **усиливает определённые изменения мира**:

| Intent | Усиливает | Ослабляет |
|:---|:---|:---|
| `healing` | Снижение toxicity | — |
| `cleansing` | Снижение toxicity, снижение disturbance | — |
| `growth` | Рост fertility | — |
| `protection` | Снижение disturbance | — |
| `harm` | Рост toxicity, рост disturbance | — |
| `ritual` | Рост spirit_pressure | — |
| `sacrifice` | Ухудшение всех параметров | — |

**Пример:** Если игрок варит зелье с intent = `healing`, даже слабое зелье будет немного снижать токсичность мира. Если тот же игрок варит зелье без указания intent (или с intent = `harm`), мир может остаться неизменным или ухудшиться.

## 10.4 Как игрок узнаёт о влиянии intent

Игра **не объясняет intent напрямую** через туториал. Вместо этого:

- При выборе intent в интерфейсе появляется **намёк** («Это зелье будет полезно для исцеления...»)
- После варки зелья игрок видит **косвенные последствия** (например, после `cleansing` туман рассеивается)
- Со временем, через эксперименты, игрок **учится** связывать intent с результатом

## 10.5 Связь с фрагментами памяти

Чем больше фрагментов памяти собрано, тем **точнее игрок может предсказать** влияние intent на результат. При низком количестве фрагментов intent даёт лишь слабый эффект; при высоком — эффект максимален.

## 10.6 Инварианты

- Intent **не изменяет базовые формулы** Process System
- Intent влияет только на **Zaryana** (этап 11) и **World Evolution** (этап 14)
- Intent **не обязателен** — игрок может варить зелья без выбора intent (используется значение по умолчанию)
- Эффект intent **накапливается** — каждое зелье с intent вносит свой вклад в эволюцию мира
