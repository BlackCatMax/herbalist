# 12. Смена биомов

## 12.1 Что такое биом

Биом — это **тип местности**, определяющий:
- Какие ресурсы можно собирать
- Как выглядит ландшафт
- Какая фоновая музыка и звуки
- Какие сущности могут здесь жить

**Биомы в игре:**

| Биом | Описание | Пример |
|:---|:---|:---|
| Смешанный лес | Умеренный, здоровый лес | По умолчанию |
| Болото | Заболоченная, токсичная местность | При высокой toxicity |
| Степь | Открытая, нарушенная местность | При высокой disturbance |
| Пустошь | Мёртвая, бесплодная земля | При низкой fertility |
| Лес (здоровый) | Плодородный, чистый лес | При высокой fertility и низкой toxicity |

## 12.2 Как меняется биом

Биом **не меняется мгновенно**. Он меняется, когда **параметры мира** пересекают определённые пороги.

### Пороги смены биома

| Текущий биом | Условие смены | Новый биом |
|:---|:---|:---|
| Любой | toxicity > 0.7 | Болото |
| Любой | disturbance > 0.6 | Степь |
| Любой | fertility < 0.3 | Пустошь |
| Любой | fertility > 0.7 и toxicity < 0.3 | Лес (здоровый) |
| Иначе | — | Смешанный лес |

### Пример: Лес → Болото

1. Игрок варит много «грязных» зелий (высокая corruption, distortion)
2. Токсичность мира постепенно растёт: 0.1 → 0.3 → 0.5 → 0.7
3. При toxicity = 0.7 биом меняется на **Болото**
4. Игрок видит: лес начал заболачиваться, трава меняет цвет, появляется туман
5. Сущности меняются: Леший исчезает, появляются Водяной и Кикимора
6. Ресурсы меняются: исчезают лесные травы, появляются болотные

## 12.3 Можно ли вернуть биом назад

**Да**, биомы обратимы — но для этого нужно **противоположное действие**:

| Чтобы вернуть | Нужно |
|:---|:---|
| Из болота в лес | Снизить toxicity ниже 0.5 (через `cleansing` и `healing`) |
| Из степи в лес | Снизить disturbance ниже 0.4 |
| Из пустоши в лес | Поднять fertility выше 0.5 |

**Важно:** Порог возврата **ниже** порога ухода (гистерезис), чтобы биомы не «мерцали» при малых колебаниях.

## 12.4 Что меняется при смене биома

| Аспект | Что происходит |
|:---|:---|
| **Визуал** | Меняется ландшафт, цвета, освещение, туман |
| **Звук** | Меняется фоновая музыка, звуки ветра, птиц, насекомых |
| **Ресурсы** | Меняется список доступных растений и минералов |
| **Сущности** | Одни исчезают, другие появляются |
| **Параметры сбора** | Меняются коэффициенты (k_axis_eco, k_meta_eco) |

## 12.5 Как игрок узнаёт о смене биома

Игра **не показывает** «Биом изменился на Болото». Вместо этого:

- Игрок **видит** изменения: трава желтеет, появляется туман, вода темнеет
- Игрок **слышит** изменения: музыка становится более мрачной
- Игрок **замечает** изменения в ресурсах: привычных трав больше нет
- Игрок **встречает** новых сущностей: вместо Лешего — Водяной

## 12.6 Связь с сущностями

Смена биома — **главный триггер** для миграции сущностей. Когда меняется биом, полностью пересчитывается состав сущностей в локации.

## 12.7 Инварианты

- Смена биома **детерминирована** (одинаковые параметры → одинаковый биом)
- Смена биома происходит **только при пересечении порогов**
- Порог возврата **ниже** порога ухода (гистерезис)
- При смене биома **полностью обновляется** состав сущностей и доступные ресурсы
- Игрок может намеренно менять биом, воздействуя на параметры мира
