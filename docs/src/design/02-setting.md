# 2. Сеттинг и интерпретация (славянский контекст)

Игра **Herbalist** разворачивается в **Древней Руси IX века**, в мире языческих верований, где природа одушевлена, но нет ярко выраженной магии.

Вместо заклинаний – фольклор, поверья, мистическое восприятие. Все механики GDD остаются неизменными, меняется только слой интерпретации (Perception System, тексты, UI).

## Фольклорное соответствие параметров

| Параметр | Фольклорная интерпретация |
|:---|:---|
| `fertility` | Мать Сыра Земля – благословенная земля. Низкое значение – «заложное», «пустое» место. |
| `moisture` | Водяные, русалки, болотники. Оптимум – «живая вода» из родников. |
| `competition` | Чащоба, глухомань – лешие и кикиморы. |
| `disturbance` | Человеческое влияние – межи, пепелища, выгоны. |
| `toxicity` | Поганое место – где скот не ходит, трава не растёт. |
| `altitude` | Красные горки, курганы, Лысая гора – священные места. |

## Morok как наваждение

Единственный нелинейный механизм – Morok – интерпретируется как «морок», «наваждение», «бесовщина». Когда игрок собирает траву в месте с высоким distortion (λ), Perception System может показывать ложные свойства (например, завышенный potency). Это не магия, а обман чувств – типичный фольклорный мотив.

## Perception и Memory в славянском ключе

- **Clarity** – «ясность», «трезвость ума». Низкая clarity → игрок слышит шёпот, видит тени, но это галлюцинации.
- **Corruption_memory** – накопленное «влияние нечистой силы». Чем больше игрок взаимодействовал с «погаными» местами, тем выше этот параметр.
- **Knowledge System** – вместо «паттернов» – предания, поверья, знахарские рецепты. Например: «На Купалу трава плакун на болотах силу набирает».

## Примеры ресурсов с народными названиями

| Ресурс | Типичные параметры | Фольклорный смысл |
|:---|:---|:---|
| Плакун-трава | potency=0.9, purity=0.8, nature=0.8 | Собирается на болотах на рассвете. Отгоняет нечисть. |
| Разрыв-трава | potency=0.6, resonance=0.9, spirit=0.9 | Растёт у старых дубов. Открывает замки, но искажает восприятие. |
| Слеза русалки (вода) | purity=0.9, corruption=0.2 | Капли на листьях у реки в полнолуние. Лечит «порчу». |
| Мёртвая вода | potency=0.2, corruption=0.8 | Собирается ночью на токсичных болотах. Используется в обрядах, опасна. |

## Ограничения – чего НЕТ в сеттинге

- Никаких магических школ, заклинаний, маны.
- Никаких духов как самостоятельных сущностей с параметрами (они только в тексте).
- Никаких новых параметров, только переименование/интерпретация существующих.
- Нелинейность только через Morok (мистическое искажение, а не колдовство).
