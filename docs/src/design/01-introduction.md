# 1. Введение

Игра представляет собой системную алхимию, в которой игрок взаимодействует с миром через сбор ресурсов, их преобразование и анализ результата.

Основой игрового процесса является цикл:

наблюдение → действие → результат → интерпретация

Игрок не следует готовым рецептам, а учится понимать поведение системы через опыт.

Мир реагирует на действия игрока. Изменения не являются изолированными — они влияют на последующие циклы взаимодействия.

Таким образом, каждый результат становится частью следующего решения.

## Системная рамка мира

Мир игры можно рассматривать через три взаимосвязанных состояния:

Явь — наблюдаемая реальность, в которой игрок собирает ресурсы и формирует условия.

Навь — источник искажений, проявляющийся как нестабильность и непредсказуемость результатов.

Правь — принцип упорядочивания, через который результат принимает завершённую форму.

Игрок не взаимодействует с ними напрямую как с отдельными системами.

Они проявляются через процессы, с которыми он работает.

## Роль игрока

Игрок выступает в роли исследователя.

Он:

- наблюдает мир  
- формирует гипотезы  
- проверяет их через действия  
- интерпретирует результат  

Контроль достигается не через прямое управление параметрами, а через понимание закономерностей.

## Принципы дизайна

Игра строится на следующих принципах:

- отсутствие жёстко заданных рецептов  
- зависимость результата от условий  
- влияние порядка действий  
- наличие нестабильности  
- обучение через опыт  

Эти принципы формируют единое пространство, в котором игрок учится работать с системой.

## Цикличность

Игровой процесс не является линейным.

Каждое действие:

- изменяет состояние мира  
- влияет на доступные ресурсы  
- формирует новые условия  

Это создаёт замкнутый цикл, в котором:

действие → изменение → новое действие

Игрок постепенно осваивает этот цикл и начинает использовать его осознанно.
