# 9. Динамика опыта игрока

Игровой опыт изменяется по мере взаимодействия с системой.

Игрок проходит через несколько состояний восприятия.

## 9.1 Начальное состояние

Игрок:

- не понимает закономерностей  
- действует интуитивно  
- часто сталкивается с неожиданными результатами  

Мир ощущается как нестабильный и непредсказуемый.

## 9.2 Формирование гипотез

Игрок начинает:

- замечать повторяемость  
- связывать условия и результат  
- формировать предположения  

Появляется ощущение контроля, но оно остаётся частичным.

## 9.3 Столкновение с искажением

Игрок сталкивается с ситуациями, где:

- ожидаемый результат не совпадает с фактическим  
- наблюдения противоречат друг другу  

Это разрушает уверенность и требует пересмотра понимания.

## 9.4 Углубление понимания

Игрок начинает учитывать:

- больше условий  
- контекст  
- нестабильность системы  

Понимание становится более гибким.

## 9.5 Осознанное управление

Игрок:

- предвидит возможные исходы  
- принимает решения с учётом риска  
- осознанно работает с нестабильностью  

Контроль остаётся неполным, но становится осмысленным.
