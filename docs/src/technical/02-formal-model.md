# 2. ФОРМАЛЬНАЯ МОДЕЛЬ

## 2.1 Структура вектора

Состояние системы представляется в виде структуры:

**Vector = {Axes, Meta}**

**Axes (оси):** Набор непрерывных параметров в диапазоне [-1, 1]:
- body – телесное воздействие
- mind – ментальное воздействие
- spirit – духовное воздействие
- nature – природное воздействие

**Axes** описывают направленность эффекта.

## 2.2 Мета-параметры (Meta)

**Meta** — набор скалярных параметров в диапазоне [0, 1]:
- potency – сила эффекта
- purity – однородность (1 – идеально однороден)
- stability – устойчивость (1 – максимально стабилен)
- resonance – согласованность с гармоничным состоянием
- corruption – степень отклонения (0 – нет отклонения)
- distortion – уровень искажения (вычисляется в Morok, добавляется в Meta только после него)

**Meta** описывает свойства состояния, но не его направление.

## 2.3 Модификаторы (Modifiers)

**Modifiers** — внешние параметры, не входящие в Vector.

Характеристики:
- не принадлежат Axes или Meta
- не сохраняются в финальном Resource (за исключением производных эффектов)
- используются в вычислениях

Примеры:
- clarity [0,1] – ясность восприятия (из Memory System)
- pressure [0,1] – давление процесса (из Alchemy и среды)
- corruption_memory [0,1] – накопленное искажение (из Memory System)

Роль:
- участвуют в вычислении distortion (Morok)
- могут влиять на коэффициенты преобразований (например, pressure в Conflict Resolution)

## 2.4 Математические операции

Все операции в системе обладают следующими свойствами:
- непрерывность (continuity)
- детерминированность (determinism)
- отсутствие ветвлений (if/else)

### Базовые операции

- **Аддитивная агрегация:** `value = Σ(value_i × weight_i)`
- **Мультипликативное масштабирование:** `value = value × k`
- **Линейная интерполяция (lerp):** `lerp(a, b, t) = a + (b - a) × t`
- **Разность и приращение:** `Δ = f(state)`, Δ является вспомогательной величиной и не входит в Vector.

### Допустимые функции

Разрешены только функции, удовлетворяющие условиям: непрерывность, отсутствие разрывов и скачков, предсказуемое поведение.

**Допускаются:** `abs(x)`, `sign(x)` (при sign(0)=0), `min(x, y)`, `max(x, y)`, степенные функции (`x^n`, `sqrt(x)`), тригонометрические функции (`sin`, `cos`) – только в адаптерах контекста, smoothstep.

### Ограничения применения

- **Morok** — единственный механизм, который применяет нелинейность к приращению Δ и изменяет динамику системы.
- **Interaction Rules** используют только линейные и кусочно-линейные операции; допускают композиционную нелинейность как результат последовательности.
- **Context Adapters** допускают использование тригонометрических и других гладких функций; не влияют на структуру модели.

### Работа с диапазонами

- Промежуточные значения могут выходить за пределы стандартных диапазонов и не ограничиваются (без clamp).
- Исключение: допускается clamp для служебных коэффициентов (например, λ в Morok) и параметра t в smoothstep.
- Финальная нормализация выполняется только один раз после Zaryana.

### Принцип единства операций

Все преобразования выполняются через единый набор операций. Запрещено вводить специальные функции под частные случаи, использовать дискретные переходы, добавлять скрытые вычисления вне модели.

## 2.5 Ограничения и нормализация

Система использует **единую политику ограничений**, разделяющую вычисления и финальную нормализацию.

### Общий принцип

В процессе вычислений:
  - значения **не ограничиваются**;
  - допускается выход за стандартные диапазоны;
  - это соответствует «нестабильным игровым зонам».

После завершения Process System:
  - применяется **единственный финальный clamp**.

### Диапазоны параметров

Финальные допустимые диапазоны:
- **Axes:** `axes ∈ [-1, 1]`
- **Meta:** `meta ∈ [0, 1]`
- **Исключение:** `distortion` уже находится в диапазоне [0,1] по определению и не изменяется clamp.

### Политика clamp

**Разрешено:** один финальный clamp после Zaryana; локальный clamp для служебных коэффициентов (например, λ в Morok; параметр t в smoothstep).

**Запрещено:** применять clamp к состоянию S (axes, meta) внутри Process System; выполнять промежуточную нормализацию; использовать clamp как часть игровой логики.

### Сохранение структуры

Axes и Meta остаются раздельными структурами; не преобразуются друг в друга. Modifiers не становятся частью Vector и не проходят через нормализацию.

### Поведение при выходе за границы

Если значения выходят за пределы диапазонов: система не корректирует их немедленно; значения участвуют в дальнейших вычислениях; возможны эффекты усиления Morok, нестабильные состояния, экстремальные взаимодействия. Это часть дизайна и не считается ошибкой.

### Гарантия корректности

После применения финального clamp все параметры находятся в допустимых диапазонах и соответствуют структуре Vector; результат валиден для передачи в Output Layer и пригоден для интерпретации системой восприятия.

### Инвариант нормализации

clamp применяется **ровно один раз**; место применения фиксировано; изменение этого правила нарушает детерминизм и предсказуемость системы.

## 2.6 Morok (искажение) – качественное описание

Реализация искажения (Morok) приведена в разделе 3.5 ((вычисление λ, искажение Δ, обновление состояния)).
Здесь даётся только смысловая интерпретация: Morok – единственный нелинейный механизм, искажающий приращение параметров в зависимости от коррупции, нечистоты, давления, памяти и ясности.

## 2.7 Обработка отрицательных коэффициентов контекста

При применении контекстных коэффициентов (k_axis, k_meta) к параметрам:
- Для мета-параметров (meta): итоговый коэффициент вычисляется как `k_meta_effective = max(k_meta, 0)`. Мета-параметры не могут стать отрицательными.
- Для осей (axes): знак k_axis сохраняется. Отрицательное значение интерпретируется как инверсия оси (умножение на отрицательное число допустимо).

## 2.8 Определение Partial Process и нейтрального состояния

**partial_process** — это Process System **без этапа Morok (3.5)**. Используется внутри последовательной агрегации (fold) для композиции ингредиентов.

Формально: `partial_process = Process \ {Morok stage}`

Все остальные этапы (Context Modifiers, Water Application, Axis Sign Modifiers, Interaction Rules, Conflict Resolution, Collapse, Zaryana) сохраняются.
Final Clamp НЕ входит в partial_process и применяется только один раз после завершения полного Process System.
Мета-параметр distortion не вычисляется в partial_process; он будет вычислен один раз после завершения fold при применении полного Morok.

**Нейтральное состояние (Identity Element)** – начальное состояние для fold:

S0:
axes = (0, 0, 0, 0)
potency = 0
purity = 1
stability = 1
resonance = 0.5
corruption = 0


Это состояние удовлетворяет: `Process(S0, I, w) = Process(I, w)` для любого I, w. Изменение этого состояния меняет всю систему.

## Инварианты формальной модели

- Фиксированная структура параметров.
- Единые операции для всех систем.
- Единый механизм искажения (Morok).
- **Morok** — единственная точка нелинейности.
- Отсутствие специальных случаев.
- Result Vector имеет ту же структуру, что и Vector (без modifiers).
- distortion не входит в исходные параметры ресурсов; он генерируется только в Process System.
- partial_process не содержит нелинейного искажения.
