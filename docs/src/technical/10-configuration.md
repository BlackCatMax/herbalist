## 10.8 Таблица влияния тегов на мир (World Effect Mapping)

Каждый BehaviorTag может оказывать влияние на параметры мира при:
- присутствии сущности с этим тегом (Entity → World Influence, раздел 4.2.7)
- сборе ресурса с этим тегом (Harvest → World Feedback, раздел 4.2.8)

### Структура записи

Для каждого тега задаётся вектор изменений:
WorldEffect = {
    fertility: float,    # изменение плодородия
    moisture: float,     # изменение влажности
    competition: float,  # изменение конкуренции
    disturbance: float,  # изменение нарушенности
    toxicity: float      # изменение токсичности
}


### Применение

**Для Entity → World Influence (раздел 4.2.7):**
Δ = WORLD_EFFECT_MAP[tag]
world.fertility += Δ.fertility * entity.intensity * K_ENTITY_WORLD_INFLUENCE


**Для Harvest → World Feedback (раздел 4.2.8):**
Δ = WORLD_EFFECT_MAP[tag]
world.fertility += Δ.fertility * resource.intensity * K_HARVEST_IMPACT
