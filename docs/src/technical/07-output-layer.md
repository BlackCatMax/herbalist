# 7. ВЫХОДНОЙ СЛОЙ

## 7.1 Результирующий вектор (Result Vector)

Result Vector — это финальное представление состояния после завершения Process System и применения Final Clamp.

## Структура

`Vector = {axes, meta}`
где:

**Axes**
`axes = {body, mind, spirit, nature}`
`axes ∈ [-1, 1]`

**Meta**
`meta = {potency, purity, stability, resonance, corruption, distortion}`

Диапазоны:
- `potency ∈ [0, 1]`
- `purity ∈ [0, 1]`
- `stability ∈ [0, 1]`
- `resonance ∈ [0, 1]`
- `corruption ∈ [0, 1]`
- `distortion ∈ [0, 1]`

## Источник значений

- `axes`, `potency`, `purity`, `stability`, `resonance`, `corruption`
  → результат после Zaryana + Final Clamp
- `distortion`
  → напрямую из Morok (без изменения в последующих этапах)

## Свойства

- все значения нормализованы
- структура фиксирована
- отсутствуют modifiers
- отсутствует Δ
- отсутствуют промежуточные параметры

## Гарантии

- все значения находятся в допустимых диапазонах
- Vector пригоден для:
  - генерации ресурса
  - интерпретации системой восприятия
  - сериализации

## Ограничения

- Vector является неизменяемым (immutable)
- любые изменения требуют повторного запуска пайплайна

## Инварианты

- структура Vector одинакова для всех ресурсов
- отсутствуют скрытые поля
- порядок параметров фиксирован
- distortion присутствует всегда

Результат — нормализованный и завершённый вектор состояния, являющийся основой для всех последующих систем.


## 7.2 Ресурс (финальная форма)

Resource (final) — материализованное представление Result Vector. Единственная переносимая форма результата.

**Содержит:**
- `axes` (копия из Result Vector)
- `meta` (копия из Result Vector, включая `distortion`)
- идентификатор (опционально)

**Свойства:**
- иммутабелен (не изменяется после создания)
- создаётся один раз
- любые изменения создают новый Resource
- при повторном использовании Resource как ингредиента его `distortion` игнорируется (обнуляется в Input Assembly)

**Преобразование:**
Resource.axes = ResultVector.axes
Resource.meta = ResultVector.meta

Преобразование является структурным отображением (копированием), никакие значения не изменяются.

## 7.3 Система восприятия (Perception)

Perception — преобразование Resource в форму, понятную игроку. Интерпретирует параметры, генерирует описания, категоризирует эффекты.

**Вход:**
- Resource (final)
- modifiers: `clarity` (из Memory System), `distortion` (из Resource.meta)
- Knowledge System (уровень понимания игрока)
- Context_view (условия восприятия, например, интерфейс)

**Выход:**
- Perceived Representation (визуальные данные, текстовые описания, абстрактное представление)

**Функции:**
- числовые значения → текст
- axes → тип эффекта (например, body → физическое воздействие)
- meta → интенсивность / качество / степень искажения
- учёт `distortion`: при высоком значении отображение может быть искажено (ложные свойства, неточные числа)
- учёт `clarity`: низкая clarity увеличивает неопределённость (размытые описания, скрытые параметры)

**Свойства:**
- не изменяет Resource
- не влияет на Pipeline
- является детерминированной функцией при фиксированных входных данных
- не выполняет нелинейных преобразований (только интерпретация)

**Формально:**
Perception(Resource, Knowledge, Context_view, clarity) → Representation

## 7.4 Пользовательский интерфейс (UI)

UI — визуализация результата Perception.

**Функции:**
- отображение информации (шкалы, цвета, формы, анимации, текст)
- визуальные метафоры (например, «морок» – размытие, искажение шрифта)
- взаимодействие с игроком (выбор ингредиентов, запуск процессов)

**Свойства:**
- не изменяет данные
- не влияет на вычисления
- полностью отделён от модели
- не содержит логики преобразования
- не работает с GameplayParams или context напрямую

## Инварианты выходного слоя

- Result Vector не изменяется после вычисления.
- Resource является иммутабельным.
- Perception не влияет на данные и не изменяет Resource.
- UI не содержит логики преобразования.
- Разделение уровней: Модель (Result Vector → Resource) → Интерпретация (Resource → Perception) → Отображение (Perception → UI).
- `distortion` сохраняется в Resource, но при повторном использовании игнорируется.
