# TECH v1.2 — Overview

Система описывает трансформацию состояния через приращения (Δ).

## Инварианты

1. Все преобразования до Morok применяются одинаково к S и Δ
2. Morok искажает только Δ
3. Δ применяется к S только один раз
4. Clamp выполняется только в самом конце
5. Все функции детерминированные и непрерывные
6. Нелинейность разрешена только в Morok и Zaryana
