## Как читать

- **Команды контроллера** (`HarvestHere`, `SaveGame`, `TalkTo X Y`) вводятся в
  консоль как есть. Строковые аргументы с пробелами или запятыми — в кавычках.
- **Команды менеджера сетки** (`ShowShrines`, `ShowJournal`,
  `ShowZaryanaStatus`, `DumpTrace`, `ReplayLastTick`, `SeedPointsOfInterest`)
  консоль сама не находит: Exec-функции ищутся только у контроллера, пешки,
  HUD и GameMode. Вызывать через `ke * <Команда>` — движок вызовет функцию у
  каждого объекта мира, в ответ напишет `Called '<Команда>' on everything in
  the world and N instances succeeded`.
- **Консольные переменные-команды** (`Herbalist.Graph.Print`,
  `Herbalist.Debug.ToggleCellDistortion`) — как есть.
- `X Y` — координаты клетки: из паспорта мира (раздел 1) или из `IA_Info`.
- Строки лога в таблицах скопированы из кода (`UE_LOG`) или из настоящего
  прогона; `…` — меняющиеся числа и имена.
- Нашли расхождение — порядок действий «Что делать при находке» в
  `ENGINE_VERIFICATION_GUIDE.md`.

## Поддержка

Новая Exec- или консольная команда обязана попасть в свой раздел:
`py tools/docs_audit/audit_docs.py --only C12` покажет неописанные.
