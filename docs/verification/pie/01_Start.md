# 1. Запуск и паспорт мира

**Зачем.** За минуту понять, что мир собрался, прежде чем проверять
что-либо ещё. Без этого любая следующая проверка отлаживается вслепую.

## Перед запуском

- Карта — `L_TestDev` (`GameDefaultMap` в `Config/DefaultEngine.ini`).
  `L_Playtest` — восемь полос биомов, но без PCG и травы.
- Правки мира **сохранены**. PIE берёт мир из редактора вместе с
  несохранёнными правками, коммандлеты и сейвы — с диска.
- Прошлый лог скопирован, если он нужен: каждый запуск, включая прогон
  тестов, перезаписывает `ProjectHerbalist/Saved/Logs/ProjectHerbalist.log`.
- Консоль в PIE — клавиша `` ` `` (тильда). Подробный вывод своего канала:
  `log LogHerbalistWorld Verbose`.

## Клавиши

Раскладка — ассеты `Content/Input/IMC_Default` и `IMC_MouseLook`; сами
клавиши здесь не перечислены намеренно — они меняются в ассете, а не в коде.
Действия: `IA_Move`, `IA_Look`, `IA_Jump`, `IA_Info`
(сведения о клетке под прицелом), `IA_Inventory`, `IA_ApplyAlchemy`,
`IA_Interact`. Что из них привязано в этом запуске — строки `Ввод:` выше.

## Как пользоваться

Окон нет — всё руками и взглядом. Одна клавиша действия: «Взаимодействие»
(`IA_Interact`, E) делает то, что подходит цели под прицелом — она же
подсвечена. «Котомка» — `IA_Inventory` (I), «Сведения» — `IA_Info` (ПКМ).

| Что | Как |
|---|---|
| Собрать траву | взгляд на растение, «Взаимодействие» пустой рукой (с предметом в руке растение не срывается) |
| Набрать воду | пустой рукой, взгляд на воду, «Взаимодействие» |
| Открыть пестерь | «Котомка» — перед камерой пять мешочков, стоят на месте: мышью водишь прицелом по ним; ещё раз — закрыть |
| Взять в руку | взгляд на предмет в пестере, «Взаимодействие» — пестерь закрылся, предмет в руке |
| Убрать из руки | «Котомка» с предметом в руке |
| Осмотреть | «Сведения» с предметом в руке — поднести к глазам, строка ощущения; ещё раз — опустить |
| Сведения о клетке | «Сведения» пустой рукой |
| Применить предмет | предмет в руке, взгляд на цель, «Взаимодействие»: котёл — положить; земля — вылить зелье, посадить на грядку, перегной, хворост — лагерь; тайник — заказ; камень — подношение; хранилище — положить |
| Помешать котёл | пустой рукой, взгляд на котёл, «Взаимодействие» |
| Хранилище | пустой рукой, «Взаимодействие» — раскладка, как пестерь; взять — так же |
| **Пояс** | посмотреть **круто вниз** (ниже 45°) — четыре заглушки, стоят на месте, мышью водишь прицелом: инструмент, контейнер, оберег, семенной мешочек. Надеть — предмет в руке + «Взаимодействие» по поясу; снять — пустой рукой + «Взаимодействие» по нужной заглушке; мешочек пустой рукой — сбор на семена / обычный |
| Артефакт на себя | «Сведения» (к лицу), затем «Взаимодействие» |
| Говорить с хозяином места | взгляд на видимый силуэт, «Взаимодействие»; колесо мыши — выбрать ответ, «Взаимодействие» — сказать, «Котомка» — уйти |
| Спать и сохраниться | пустой рукой на лавку, «Взаимодействие» |
