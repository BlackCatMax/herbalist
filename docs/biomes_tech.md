## 12.1 Назначение

Система биомов описывает:

* локальное состояние мира
* формирование среды для ресурсов
* влияние Морока и Заряны
* динамику изменений под действием игрока

---

## 12.2 Представление мира

Мир представлен сеткой узлов:

```
World = {WorldNode_i}
```

---

### Узел:

```
WorldNode:
    position
    biome_type
    S_i = (toxicity, fertility, disturbance, moisture, competition)
    
    M_i ∈ [0,1]  # Morok
    Z_i ∈ [0,1]  # Zaryana
    
    context
    modifiers
```

---

## 12.3 Базовое состояние биома

Каждому биому соответствует эталон:

```
B0_k = (tox_k, fert_k, dist_k, moist_k, comp_k)
```

---

### Примеры:

Болото:

```
toxicity = 0.7
fertility = 0.6
moisture = 0.9
disturbance = 0.3
competition = 0.5
```

---

Лесостепь:

```
toxicity = 0.3
fertility = 0.7
moisture = 0.5
disturbance = 0.4
competition = 0.6
```

---

## 12.4 Определение биома

Состояние узла:

```
S_i ∈ [0,1]^5
```

---

Метрика:

```
D_k(S_i) =
    Σ w_n · |S_i[n] - B0_k[n]|
```

---

Биом определяется как:

```
biome_type = argmin_k D_k(S_i)
```

---

## 12.5 Динамика состояния

---

### Общее уравнение:

```
S_i(t+1) =
    S_i
  + ΔMorok
  + ΔZaryana
  + ΔDiffusion
  + ΔPlayer
  + ΔRelaxation
```

---

## 12.6 Морок

---

```
ΔMorok =
    M_i · G_morok(S_i)
```

---

Эффекты:

* увеличение toxicity
* увеличение disturbance
* добавление шума

---

## 12.7 Заряна

---

```
ΔZaryana =
    Z_i · G_zaryana(S_i, B0_k)
```

---

Где:

```
G_zaryana направлен к B0_k
```

---

### Убывающая эффективность:

```
Z_eff = Z_i / (1 + Z_i)
```

---

## 12.8 Овервосстановление

---

Если:

```
Z_i > Z_threshold
```

---

```
ΔZaryana += drift_vector
```

---

Где:

```
drift_vector уводит S_i за пределы B0_k
```

---

## 12.9 Сопротивление биома

---

```
R_k = k · distance(S_i, B0_k)
```

---

```
ΔZaryana *= (1 - R_k)
```

---

---

## 12.10 Релаксация

---

```
ΔRelaxation =
    -λ · (S_i - B0_k)
```

---

---

## 12.11 Диффузия

---

```
ΔDiffusion =
    Σ_j flow_ji · (S_j - S_i)
```

---

---

## 12.12 Поля Морока и Заряны

---

### Морок:

```
M_i(t+1) =
    M_i
  + α · diffusion
  + emission
  - β · Z_i · M_i
```

---

### Заряна:

```
Z_i(t+1) =
    Z_i
  + γ · diffusion
  + shrine_power
  - δ · M_i · Z_i
```

---

---

## 12.13 Влияние игрока

---

После применения эффекта:

```
M_i += f(result.corruption, result.resonance)
Z_i += f(result.stability, result.purity)
```

---

---

## 12.14 Формирование Context

---

```
toxicity = M_i
fertility = Z_i
disturbance = M_i · (1 - Z_i)
moisture = B0_k.moisture
competition = B0_k.competition
```

---

```
Context_i = f(S_i)
```

---

---

## 12.15 Переход биомов

---

Биом изменяется, если:

```
D_new < D_current
```

---

Особенности:

* переход непрерывный
* нет мгновенных скачков

---

---

## 12.16 Устойчивость

---

Каждый биом имеет:

```
basin_of_attraction
```

---

Если:

```
S_i ∈ basin
```

→ возвращение к B0_k

---

---

## 12.17 Граничные зоны

---

Если:

```
|S_i - S_neighbors| ↑
```

---

Тогда:

* высокая вариативность ресурсов
* высокая нестабильность
* повышенный resonance

---

---

## 12.18 Формирование ресурсов

---

### Плотность:

```
density ∝ fertility · moisture
```

---

### Качество:

```
quality ∝ Z_i · (1 - disturbance)
```

---

### Искажение:

```
mutation ∝ M_i
```

---

### Вариативность:

```
variation ∝ |∇S_i|
```

## 12.20 Порядок обновления

---

Строгий порядок:

```
1. Применение результата игроком
2. Обновление M_i, Z_i
3. Обновление S_i
4. Диффузия
5. Релаксация
6. Пересчёт biome_type
7. Обновление ресурсов
```

---

---

## 12.21 Инварианты

---

1. Биом — производное от S
2. Изменения происходят локально (на уровне узла)
3. Нет глобальных переключений биомов
4. Мир стремится к B0 при отсутствии воздействия
5. Морок и Заряна влияют только через состояние
6. Pipeline алхимии не изменяется
