# Документы проекта

Инженерные документы Herbalist. Канон игры (GDD, глоссарий, компендиум) —
в `herbalist_docs/Herbalist_Vault/`; здесь то, что сопровождает разработку.
Летопись — `CHANGELOG.md`, открытое — `ROADMAP.md` (оба в корне).

Имена файлов при переносе из корня (2026-09-14) не менялись: ссылки вида
`DESIGN_World_Layout.md §5` в коде, CHANGELOG и других документах ищутся по
имени.

## `design/` — дизайн-предложения и планы

Черновики, не канон: принятое переходит в GDD или в
`03_Technical/Current` хранилища.

| Файл | О чём |
|---|---|
| `DESIGN_World_Layout.md` | Разметка мира: сетка, увязанная с World Partition, страницы, чанки, сейвы (решения и этапы реализации) |
| `DESIGN_World_State.md` | Хранение состояния мира и связность зависимостей |
| `DESIGN_Community_And_Homestead.md` | Диалоги, торговля, подношения, жилище, инструменты |
| `DESIGN_Brewing_Situations_And_Lore.md` | Ситуации варки, POI и лорные прецеденты |
| `DESIGN_Entity_Actors_Art.md` | Визуал проявления сущностей |
| `DESIGN_POI_Art_And_LevelDesign.md` | Точки интереса: визуал, левел-дизайн, звук |
| `DESIGN_UI_Implementation_Plan.md` | План реализации UI по двум ресёрчам |
